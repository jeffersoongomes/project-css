# Projeto de Estilização CSS

Aplicação web desenvolvida durante o curso de Análise e Desenvolvimento de Sistemas para praticar conceitos de HTML5 e CSS3.

## 🛠️ Tecnologias Utilizadas
- **HTML5:** Estruturação semântica da página.
- **CSS3:** Estilização, layout responsivo e efeitos visuais.

## 📂 Arquivos do Projeto
- `Equação.html`: Estrutura principal da página web.
- `estilos.css`: Folha de estilo contendo as regras de design e formatação.

## 🚀 Como visualizar
Basta baixar ou clonar o repositório e abrir o arquivo `Equação.html` em qualquer navegador web.
